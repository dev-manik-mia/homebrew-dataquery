# DataQuery for Homebrew

```sh
brew install dev-manik-mia/dataquery/dataquery
```

or, after `brew tap dev-manik-mia/dataquery`, just `brew install dataquery`.

DataQuery updates itself (Settings → About → Updates). `brew upgrade --greedy dataquery`
also updates it. The cask is regenerated by the DataQuery release workflow
(`scripts/homebrew-cask.sh`); don't edit `Casks/dataquery.rb` by hand.
